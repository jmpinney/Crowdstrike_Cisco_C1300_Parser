# Crowdstrike_Cisco_C1300_Parser
A Crowdstrike NG-SIEM parser for Cisco C1300 small business switches. The Catalyst and iOS parsers do not work with the C1300 series.

Event mapping is ongoing as Cisco doesn't publish the complete list facility/event codes for the C1300 so I can only add new events if I observe the event so a ton of events are unmapped.

Currently mapped:
LINK
AAA
COPY
STP
SYSLOG
